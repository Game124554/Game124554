Realistic Overhaul 2.1.0 for Minecraft Java 1.20.1 (Fabric).

Install: put `realistic-overhaul-2.1.0.jar` in `.minecraft/mods` together with Fabric API for 1.20.1 (Fabric Loader 0.14.21 or newer).
Settings: press **O** in game, or Options > Realistic Overhaul...

New in 2.1.0:
- Puddles with irregular shapes that join together, a wet shiny look and rain ripples.
- Snow dunes and drifts against walls, smooth wavy snow surface, blowing snow.
- Creepy mobs: hunched limping zombies, twitching skeletons and endermen, breathing creepers, fidgeting spiders, glowing eyes in the dark.

From 2.0.0: NoCubes-style smooth terrain, realistic terrain generation for new worlds, step-up, limb ragdolls, blood, limping hurt mobs.
Smooth terrain needs Indium if you use Sodium.
