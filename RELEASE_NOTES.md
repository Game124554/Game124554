Realistic Overhaul 2.0.0 for Minecraft Java 1.20.1 (Fabric).

Install: put `realistic-overhaul-2.0.0.jar` in `.minecraft/mods` together with Fabric API for 1.20.1 (Fabric Loader 0.14.21 or newer).
Settings: press **O** in game, or Options > Realistic Overhaul...

New in 2.0.0: NoCubes-style smooth terrain, realistic terrain generation (new worlds), 1-block step-up with smooth camera, limb ragdolls on corpses, blood splatter, hurt mobs limp, scrollable settings screen with more options.
